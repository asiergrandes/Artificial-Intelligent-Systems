# Artificial Intelligent Systems Labs & Project

This repository contains laboratory assignments and a final project developed during the **Artificial Intelligent Systems** course at the **University of Ljubljana** as part of the Erasmus programme.

The repository combines practical applications of machine learning, data analysis and intelligent systems using different tools and approaches.

---

# Laboratory Assignments

## Face Detection and Computer Vision

Implementation of face detection techniques and image analysis using computer vision tools and machine learning approaches.

### Main topics

* Face detection
* Image processing
* Feature extraction
* Visual pattern recognition

---

## Machine Learning Algorithm Comparison using WEKA

Comparative analysis of different machine learning algorithms using the WEKA platform.

### Algorithms evaluated

* Logistic Regression
* Support Vector Machines (SVM)
* Random Forest
* Other supervised learning techniques

### Main topics

* Classification models
* Model evaluation
* Accuracy comparison
* Dataset preprocessing
* Performance metrics

---

## Air Quality Prediction System

Development of an air quality prediction model using real-world datasets containing environmental and pollution data from multiple cities.

The project focused on selecting the best-performing machine learning algorithm from previous experiments and applying it to predictive analysis tasks.

### Main topics

* Predictive modelling
* Environmental data analysis
* Data preprocessing
* Supervised learning
* Model optimization

### Technologies

* WEKA
* Python
* CSV datasets
* Machine Learning algorithms

---

# Logic-Based Travel Recommendation System

Development of a recommendation system using **Prolog** for intelligent travel and restaurant suggestions.

The system allows users to:

* Suggest cities based on transport type and budget
* Recommend landmarks and travel guides
* Suggest restaurants based on cuisine, price range and rating
* Perform rule-based intelligent recommendations

### Main topics

* Logic programming
* Knowledge representation
* Rule-based systems
* Intelligent recommendation systems
* Decision support systems

### Technologies

* Prolog
* Rule-based reasoning
* Knowledge databases

---

# Final Project — Sentiment Analysis of Movie Reviews

Development of a sentiment analysis system for movie reviews using multiple machine learning algorithms.

The objective of the project was to compare the performance of different classification models in detecting positive and negative sentiment from textual data.

### Main topics

* Natural Language Processing (NLP)
* Text classification
* Sentiment analysis
* Machine learning model comparison
* Data preprocessing and feature extraction

### Algorithms used

* Logistic Regression
* Support Vector Machines (SVM)
* Random Forest
* Other supervised learning models

### Technologies

* Python
* Scikit-learn
* Pandas
* NumPy
* NLP preprocessing techniques
